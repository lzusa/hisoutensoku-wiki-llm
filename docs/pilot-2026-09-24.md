# Windows 5070 Ti 首次试验（2026-09-24）

## 环境与数据

- 系统：原生 Windows，既有 Conda 环境 `py310`，Python 3.10.6。
- GPU：RTX 5070 Ti 16GB，PyTorch 2.11.0+cu128；CUDA 张量矩阵乘法已验证。
- 训练库：Transformers 5.17.0、TRL 1.13.0、PEFT 0.21.0、Datasets 5.0.1、Accelerate 1.15.0、bitsandbytes 0.50.2。
- 底座：[Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)，权重从[官方 ModelScope 页面](https://modelscope.cn/models/Qwen/Qwen3-4B-Instruct-2507)下载到本地。Hugging Face 同名仓库解析到 `cdbee75f17c01a7cc42f958dc650907174af0554`；本地主要权重文件 SHA256 前缀与该仓库文件一致。
- Wiki 上游 commit：`b03bd40710774725f8053780c547514d83fd226e`。本地人工核对问答：训练 20、开发 8、测试 8，按页面分开。原文与问答均未提交到仓库。

## 训练

本机命令：

```powershell
conda activate py310
python scripts/train.py --model data/model --train data/qa/train.jsonl --epochs 1 --max-length 512 --output outputs/pilot-lora
```

QLoRA 使用 4-bit NF4、双重量化、BF16、LoRA r=16、batch 1、累积 8。此次仅 3 个优化步骤，训练约 12.5 秒，PyTorch 报告训练期间峰值预留显存 3698 MiB，训练 loss 5.13。预留显存不是整机显存使用量。Adapter 只保存在本地 `outputs/`。

## 对照结果

开发集用于调整词法检索，因此不把开发集分数当作最终指标。调整完成后，另从未参与调参的四篇 FAQ 制作 8 条测试问答；其结果如下：

| 方法 | 测试集结果 |
| --- | --- |
| 词法检索 | 页面来源 recall@1 为 6/8，recall@3 和 recall@5 均为 8/8 |
| 原版 4B | 8 条回答都未给出所问的关键 Wiki 事实，常误把游戏故障当成 Wiki 网站故障 |
| 20 条问答 QLoRA | 同样未答出这 8 条的关键事实，未观察到改进 |
| 原版 4B + 前 3 个检索片段 | 8 条回答都给出与人工参考答案一致的核心事实，来源 URL 由程序单独记录 |

模型答案按是否回答问题所需的关键事实人工复核；这只是 8 条样本的试验，不代表通用准确率。检索增强答案仍需检查无依据的额外推断。这个试验支持先使用可追溯检索系统，再扩大人工审核数据以评估微调是否有独立价值。下一轮应增加不同角色、招式、版本差异和拒答题，并保持新测试集不参与调参。

## 本机环境影响

原有 `py310` 中已有若干依赖冲突。为运行训练，升级了 Hugging Face 相关包并把与 PyTorch 2.11 不匹配的旧 `torchvision`、`torchaudio` 换成对应的 CUDA 12.8 版本。`pix2tex` 仍要求旧版 `tokenizers==0.12.1`，与本项目使用的 0.23.2 冲突；运行 `python -m pip check` 可复核。修改前的包清单只保存在本地 `data/py310-before.txt`。
